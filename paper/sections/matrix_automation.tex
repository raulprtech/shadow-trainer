\subsection{Automated paired matrix and statistical gate}

The next physical experiment is encoded as a fail-closed matrix rather than a
collection of manually launched commands. It spans Tiny3D, NIfTI 3D,
ResNet-18, and ResNet-50; separates cold and fully warm cache conditions; and
requests three sync/prefetch repetitions per cell. Each arm runs in a new
Python process with an independent cache and output directory, yielding 48
processes in a complete matrix. The runner checks the physical Windows-volume
free-space floor before session creation, before and after warm-cache
preparation, and before each arm. After the disk gate, it validates every
source-object size and SHA-256 before session creation. It also enforces a 3-GiB ceiling on the
matrix session artifacts.

Every pair passes through a semantic auditor before its times are eligible for
analysis. Timing uses a monotonic \texttt{execution\_seconds} interval from
the ready workload state through the final training checkpoint, excluding host
inspection and model initialization; whole-process duration remains separate.
Per-arm metrics also distinguish foreground and background staging service time,
the wait exposed when a prefetched window is consumed, final and peak cache
occupancy, transferred bytes, peak VRAM, and artifact bytes.
The auditor compares the canonical manifest, job seed and workload
configuration, software and accelerator signature, a fresh-process
initialized-state hash, deterministic-algorithm status, ordered per-step trace,
checkpoint position, and structured hashes of model, optimizer, and Python,
Torch, and CUDA RNG state. A divergence stops the matrix immediately. The
summary compiler is stricter still: it suppresses all timing statistics unless
the matrix reports success, contains every protocol cell and repetition, and
has no excluded or non-exact pair. Only then does it report per-cell medians,
inclusive quartiles, and a deterministic 10,000-resample bootstrap confidence
interval for the median sync-to-prefetch time ratio.

Small CPU fixtures pass exact sync/prefetch audits for all four
workload configurations, with the Tiny3D pair launched in two independent
Python interpreters. A deliberately modified initial-state event and a modified
final checkpoint are each detected as divergent. These tests validate the audit
mechanism and adapter semantics. After compacting the WSL virtual disk, the
physical preflight observed 54,855,868,416 free bytes and the full CUDA matrix
completed on the RTX 3050 Ti. All 24 pairs passed every semantic check, with no
excluded pair. In the cold-cache NIfTI3D cell, the median audited execution time
was 4.9572~s for sync and 3.4889~s for prefetch, a median ratio of 1.4209 with a
10,000-resample bootstrap 95\% interval of [1.2842, 1.4739]. Cold ResNet-18
also had an interval above one, whereas every warm-cache interval and the other
cold-cache cells crossed one. We therefore interpret prefetch as a conditional
latency-hiding mechanism rather than a universal training accelerator; the
complete eight-cell table and the low count of three pairs per cell must
accompany any performance statement.
